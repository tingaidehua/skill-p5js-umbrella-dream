# 接住星星的伞

一把被风掀翻的线框伞，在阵风里接住星星，再把它们吹向天空。竖版 3:4 的 p5.js 生成艺术，约 69 秒，带原创配乐。

**在线观看：** https://tingaidehua.github.io/skill-p5js-umbrella-dream/

打开页面后点击画面开始。右下角可以开关字幕、旁白、声音，也可以复制创作轨迹。配乐文件是 `template/score.mp3`，和画面放在一起，手机静音键不会把声音吞掉。

## 仓库里有什么

| 路径 | 内容 |
|---|---|
| `template/index.html` | 可互动的完整作品 |
| `template/score.mp3` | 预渲染配乐 |
| `case/` | 字幕版成片、配乐和创作轨迹 |
| `scripts/` | 参考视频取证、逐帧渲染、合成 MP4 |
| `SKILL.md` | 给智能体复用的制作流程 |
| `references/trajectory.md` | 从参考视频到成片的迭代记录 |

本地直接用浏览器打开 `template/index.html` 即可预览。
